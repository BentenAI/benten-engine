Function encrypt_chunk 

pub fn encrypt_chunk(
    chunk_plaintext: &[u8],
    chunk_index: usize,
    total_chunks: u32,
    plaintext_cid: &Cid,
    key: &[u8],
) -> Result<AeadEnvelope, AeadError>
Expand description

Seal one chunk’s bytes at chunk_index of a chunked ciphertext whose total chunk count is total_chunks — the producer-side counterpart to decrypt_chunk. Used by sync-side bytes-as-they-arrive ingest paths that need to seal incrementally rather than materializing the whole Node first.

F3 (R6 R1 fix-pass): the caller MUST know total_chunks at seal time so the AAD commits the cross-chunk-truncation defense field. Sync-side incremental sealers compute this from the plaintext-length hint they received with the ingest stream.
